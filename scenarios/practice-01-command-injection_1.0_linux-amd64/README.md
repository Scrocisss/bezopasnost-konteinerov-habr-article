# Практика 1. Командная инъекция

Уязвимость реализована в `/app/app.py` внутри образа `container-security-lab/command-injection:1.0-vulnerable`. Обработчик `/ping` принимает параметр `host` и передаёт его в `subprocess.run` как часть строки `/bin/ping -c 1 -W 1 {host}` с `shell=True` и `/bin/sh`. Поэтому `;`, `&&`, `|` и перенаправления становятся синтаксисом оболочки. Дефект соответствует CWE-78 и позволяет выполнить произвольную команду внутри контейнера.

Compose-файл задаёт лабораторную конфигурацию и ограничения, но не исправляет уязвимость приложения. Контейнер работает от UID 10001, без capabilities, с read-only rootfs. Цель практики — обнаружить запуск дочернего исполняемого файла и отделить его от штатного `ping`.
